# Missão Santa Faustina

Site institucional da Missão Santa Faustina, comunidade católica em Fazenda Rio Grande - PR devota à Divina Misericórdia.

## Stack

- [React 19](https://react.dev) + [Vite](https://vite.dev) + [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS v4](https://tailwindcss.com) (mobile-first, tema claro/escuro)
- [React Router](https://reactrouter.com)
- [lucide-react](https://lucide.dev) + [react-icons](https://react-icons.github.io/react-icons/)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```
